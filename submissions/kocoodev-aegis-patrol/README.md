# Aegis Quadruped Patrol

A MuJoCo simulation of the bundled **Aegis** robot dog running a deterministic
patrol route: it trots forward, turns through two route waypoints, and comes to a
controlled stop. Everything is reproduced from a single script.

## Project Summary

- **Project name**: Aegis Quadruped Patrol
- **Robot platform**: Aegis quadruped (`assets/Aegis`)
- **Task goal**: Drive the robot dog along a marked patrol route with smooth
  start, two timed turns, and a controlled stop.
- **Technical approach**: An open-loop kinematic trot gait (diagonal leg pairs)
  layered on top of a base path. Forward speed and yaw rate are smooth functions
  of time, integrated per frame to produce a continuous patrol trajectory.
- **Core features**:
  - Loads the SolidWorks-exported Aegis URDF directly into MuJoCo (auto-injects
    the `<mujoco>` compiler block and resolves mesh paths).
  - Trot gait with per-leg ABAD / HIP / KNEE control.
  - Time-shaped speed and turn-rate profile for a believable patrol path.
  - Route waypoint markers and a slowly orbiting follow camera.
  - Exports both an MP4 and a sampled trajectory JSON.
- **Highlights**: Fully deterministic and reproducible; no trained policy or
  external data required.
- **Current limitations**: Kinematic showcase, not a physically closed-loop
  controller, so there is no ground-contact balance feedback.
- **Future improvements**: Replace the open-loop gait with a torque-controlled
  trot and add foot-contact scheduling for true dynamic walking.

## How to Run

From the repository root:

```bash
python3 -m pip install -r requirements.txt
python submissions/kocoodev-aegis-patrol/run_patrol_demo.py
```

Optional flags: `--duration`, `--fps`, `--width`, `--height`, `--output`,
`--trajectory`, `--urdf`.
